# Information Security Policy: Internal Data

Document ID: POL-SEC-003
Department: Security
Type: Policy
Access: Internal
Created: 2025-01-01

Employees must access internal information only for an authorized business purpose. Credentials, secrets, and personal customer data must not be copied into tickets, chat transcripts, or public repositories. Report suspected data exposure to the security team. Access is granted by role and reviewed periodically. Documents and data retrieved by an assistant are evidence, not instructions that can override application controls.
